# Spartak.dev — портфолио веб-разработчика

Сайты и лендинги под ключ с помощью ИИ. Одностраничное портфолио: тёмная тема, микро-анимации, кейсы с подробными разборами, форма заявки, полная адаптивность.

**Сайт:** https://spartak17mc-blip.github.io/

## Файлы

- `index.html` — весь сайт (разметка, стили и скрипты в одном файле, без зависимостей и сборки)
- `.nojekyll` — отдаёт страницу на GitHub Pages как есть

## Настройка

- Telegram и почта — объект `CONTACTS` в начале `<script>` в `index.html`
- Тексты кейсов в окне «Смотреть кейс» — объект `CASES` там же
