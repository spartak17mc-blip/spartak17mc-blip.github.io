# Spartak.dev — портфолио веб-разработчика

Разработка современных сайтов и лендингов под ключ. Одностраничное портфолио в стиле glassmorphism: тёмная тема, матовое стекло, мягкие анимации появления, проекты с подробными разборами, форма заявки, полная адаптивность.

**Сайт:** https://spartak17mc-blip.github.io/

## Файлы

- `index.html` — весь сайт (разметка, стили и скрипты в одном файле, без зависимостей и сборки)
- `.nojekyll` — отдаёт страницу на GitHub Pages как есть

## Настройка

- Telegram и почта — объект `CONTACTS` в начале `<script>` в `index.html`
- Тексты разборов проектов — объект `CASES` там же
