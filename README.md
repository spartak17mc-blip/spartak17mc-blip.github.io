# Spartak.dev — портфолио

Одностраничный сайт-портфолио фронтенд-разработчика: тёмная тема, адаптивная вёрстка, без фреймворков.

**Сайт:** https://spartak17mc-blip.github.io/

## Файлы

- `index.html` — весь сайт (разметка, стили и скрипты в одном файле)
- `.nojekyll` — отдаёт страницу на GitHub Pages как есть

## Контакты

Telegram и email задаются в начале скрипта в `index.html`, в объекте `CONTACTS`.
