# The Spartec Web — портфолио веб-разработчика

Разработка современных сайтов и лендингов под ключ. Одностраничное портфолио в тёмном стекле: прелоадер и экран знакомства, космическая воронка, переключатель направлений с атмосферой и звуком, панель «Обо мне», реальный кейс PULSE FIT, FAQ, способы оплаты, мини-опросник и заявки прямо в Telegram.

**Сайт:** https://spartak17mc-blip.github.io/

## Файлы

- `index.html` — весь сайт (разметка, стили и скрипты в одном файле, без зависимостей и сборки)
- `pulsefit.jpg` — превью кейса PULSE FIT
- `telegram-worker.js` — backend для заявок в Telegram (Cloudflare Worker), см. «Заявки в Telegram»
- `.nojekyll` — отдаёт страницу на GitHub Pages как есть
- Юридические тексты («Условия работы», «Политика конфиденциальности») — в `<dialog class="legal">` в конце `index.html`

## Настройка (всё в начале первого `<script>` в `index.html`)

- `CONTACTS.telegram` — ваш ник в Telegram (без @)
- `LEADS.endpoint` — адрес backend'а для заявок с формы и опросника (см. ниже)

## Заявки в Telegram

Форма «Заявка на проект» (раздел «Контакты»): **Telegram**, **Бюджет** (сумма + валюта $ / € / ₽), **Специализация**, **Описание**. Все поля обязательные. После отправки посетитель видит «Ваша заявка успешно отправлена! Я свяжусь с вами в ближайшее время», а вам в личный Telegram приходит:

```
📩 НОВАЯ ЗАЯВКА

👤 Telegram: @username
💰 Бюджет: 500 $
🎯 Специализация: Web Design
📝 Описание: полный текст от клиента
                                    [✉️ Написать клиенту]
```

Схема: сайт → `telegram-worker.js` (Cloudflare) → Telegram Bot API → ваш чат. Токен бота и ваш chat id живут только в секретах Cloudflare — в коде сайта их нет.

### Подключение (≈10 минут, бесплатно)

1. **Токен бота.** Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → имя и username бота (должен заканчиваться на `bot`). BotFather пришлёт токен вида `123456789:AAH…` — никому его не показывайте.
2. **Ваш Chat ID.** Откройте своего нового бота и нажмите **Start** (без этого бот не сможет вам писать). Затем узнайте свой id одним из способов:
   - напишите [@userinfobot](https://t.me/userinfobot) — он ответит строкой `Id: 123456789`;
   - или откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":123456789`.
3. **Backend.** [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатная регистрация) → **Workers & Pages** → **Create** → **Create Worker** → **Deploy** → **Edit code** → замените весь код содержимым `telegram-worker.js` → **Deploy**.
4. **Секреты.** В воркере: **Settings → Variables and Secrets → Add**, тип **Secret**:
   | Имя | Значение |
   |---|---|
   | `BOT_TOKEN` | токен из шага 1 |
   | `CHAT_ID` | ваш id из шага 2; несколько получателей — через запятую: `8426313033, 123456789` |
   | `ALLOWED_ORIGIN` | `https://spartak17mc-blip.github.io` (несколько адресов — через запятую, например `https://spartak17mc-blip.github.io, https://имя.vercel.app`; без `/` на конце) |
5. **Связь с сайтом.** Скопируйте адрес воркера (`https://имя.ваш-аккаунт.workers.dev`) и вставьте в `index.html`:
   ```js
   const LEADS = {
     endpoint: "https://имя.ваш-аккаунт.workers.dev"
   };
   ```
   Закоммитьте и запушьте — GitHub Pages обновит сайт.
6. **Webhook.** Один раз откройте `https://<адрес-воркера>/setup` — ответ «Webhook подключён ✓». После этого бот отвечает на `/start`: вам — «Вы получатель заявок», остальным — «Это закрытый бот».
7. **Проверка.** Адрес воркера в браузере должен ответить `Method not allowed` (если `Not configured` — не хватает секрета). Отправьте тестовую заявку с сайта — она придёт в Telegram.
8. *(Рекомендуется)* Cloudflare → **Security → WAF → Rate limiting rules**: не больше 10 запросов в минуту с одного IP на адрес воркера.

Пока `endpoint` пустой, форма не ломается: она сообщает, что отправка не подключена, и предлагает написать вам в Telegram напрямую.

### Защита от спама и подделок

- В браузере: проверка всех полей, honeypot-поле, отсев «мгновенных» отправок (< 3 с), не чаще 1 заявки в 45 с и 5 в час.
- На сервере: каждое поле проверяется заново, лимиты длины, только POST + JSON, только с `ALLOWED_ORIGIN`, honeypot и тайминг, не больше 5 заявок за 10 минут с одного IP.
- Текст сообщения собирает и экранирует сервер — клиент не может подставить свою разметку или ссылки. Сообщения уходят только в `CHAT_ID`.

### Закрытый бот

- Заявки получают только ID из `CHAT_ID`. Чтобы добавить помощника: он пишет боту `/start`, бот отвечает «Это закрытый бот. Ваш ID: …» — допишите этот ID в `CHAT_ID` через запятую (Cloudflare → воркер → Settings → Variables and Secrets). Чтобы убрать — удалите ID оттуда же.
- Всем, кого нет в `CHAT_ID`, бот отвечает только «Это закрытый бот» и ничего не показывает. Из групп и каналов он выходит сам; в @BotFather добавление в группы выключено (`/setjoingroups` → Disable).
- Webhook (`/tg`) принимает запросы только с секретным заголовком, который воркер вычисляет из токена, — подделать «сообщение от Telegram» нельзя. Если перевыпустите токен (`/revoke`), обновите `BOT_TOKEN` и снова откройте `/setup`.
- На сайте (в «Контактах» и после отправки заявки) клиентов предупреждают: настоящие аккаунты — только те, что перечислены в `CONTACTS.official`, остальные — мошенники. Ссылка «Telegram» в «Контактах» ведёт на `CONTACTS.telegram`.
- Главное, что остаётся на вас: включите в Telegram облачный пароль (Настройки → Конфиденциальность → Облачный пароль) и никому не передавайте токен бота.
- `CASES` — разбор проектов (значения — ключи перевода, см. «Языки»)
- `QUIZ_PRICE`, `QUIZ_DAYS` — ориентиры цен и сроков в опроснике

## Языки

Переключатель 🌐 в шапке (на телефоне — в меню): EN, RU, DE, ES, FR, PT, ZH, JA, KO, TR. При первом визите сайт всегда на русском; выбор посетителя запоминается.

- В разметке каждый переводимый элемент помечен атрибутом: `data-i18n="ключ"` (текст), `data-i18n-html="ключ"` (текст с разметкой), `data-i18n-attr="aria-label:ключ;placeholder:ключ"` (атрибуты).
- Русский текст берётся прямо из разметки, менять его — там же. Переводы — во втором `<script>`: `I18N_DICT` (по языкам), `I18N_ROWS` (по строке на ключ: EN, DE, ES, FR, PT, ZH, JA, KO, TR), `I18N_VIBES` (карточки сфер), `I18N_HV` (подписи в первом экране).
- Проверка полноты: откройте консоль и выполните `I18N.audit()` — покажет недостающие ключи по языкам и любой оставшийся русский текст на странице (на нерусском языке).
- Тексты опросника и кейса (`QUIZ`, `CASES`) — это ключи перевода; русские формулировки — в `I18N_DICT.ru`.
Валюта по умолчанию: RU → ₽, DE/FR/ES → €, остальные → $; посетитель может выбрать другую вручную. Заявки приходят в Telegram на русском, с полем «Язык».

## Производительность

Уровень устройства определяется один раз в `<head>` (`window.PERF`, классы `html.lite` / `html.touch`):

| Уровень | Кто | Частицы воронки | Кадры | Прочее |
|---|---|---|---|---|
| full | компьютер с 5+ потоками и 5+ ГБ памяти | 1700 | до 60 fps | разрешение 1.5×, падающие кусочки кода |
| lite | ≤4 потоков, ≤4 ГБ памяти или экономия трафика | 680 (÷2,5) | до 60 fps (30, если не успевает) | разрешение 1×, без текста, лёгкий блюр стекла |
| phone | сенсорный экран | 567 (÷3) | до 30 fps (60 во время запуска) | как lite |

- Ограничение кадров считается по времени, поэтому на экранах 90/120/144 Гц воронка не рисуется чаще, чем нужно.
- Во время прокрутки, смены сферы и смены языка воронка на мгновение снижает частоту (30 / 20 fps), чтобы страница получила ресурсы.
- Если кадры всё равно не успевают, регулятор сам уменьшает число частиц, а затем разрешение; при запасе — возвращает.
- Прокрутка — родная браузерная (плавная, в отдельном потоке). Проверка на устройстве: `cosmos.stats()` в консоли.

## Безопасность

- Заявки: очистка и проверка полей, лимиты длины, honeypot, отсев «мгновенных» отправок, ограничение частоты (в браузере и на сервере).
- Токен бота и chat_id хранятся только в секретах Cloudflare (`telegram-worker.js`); режима «токен в коде сайта» больше нет. Воркер принимает запросы только с `ALLOWED_ORIGIN`, сам проверяет поля, экранирует и собирает текст сообщения.
- Content-Security-Policy в `<head>`: только свой код, Google Fonts и HTTPS-запросы; без eval, плагинов и чужих фреймов.
